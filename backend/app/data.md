## 2. Services

Nueva Tech Solution offers four primary service lines:

---

### 2.1 Managed Cloud Services (MCS)

A fully managed cloud operations service where Nueva Tech Solution handles provisioning, monitoring, patching, cost optimization, and incident response on behalf of the client.

**What's included:**
- 24/7 infrastructure monitoring and alerting
- Auto-scaling configuration and management
- Monthly cost optimization reports
- Security patch management (OS and middleware)
- Disaster recovery planning and quarterly DR drills
- Dedicated cloud architect (available on Professional and Enterprise tiers)

**Supported Platforms:** AWS, Google Cloud Platform (GCP), Microsoft Azure

**Best for:** Companies with 20–500+ cloud workloads that lack in-house DevOps/cloud expertise.

---

### 2.2 NovaSight Analytics Platform (SaaS)

A cloud-hosted business intelligence and AI analytics platform that connects to multiple data sources, generates automated insights, and supports natural language queries.

**Key Features:**
- Connect to 80+ data sources (databases, CRMs, ERPs, spreadsheets, APIs)
- Drag-and-drop dashboard builder
- AI-powered anomaly detection and trend forecasting
- Natural language query ("Ask your data" feature)
- Scheduled reports delivered via email or Slack
- Role-based access control (RBAC)
- Data lineage and audit logs

**Deployment:** 100% SaaS (cloud-hosted by Nueva Tech Solution). Private cloud deployment available on Enterprise plan.

---

### 2.3 Enterprise Integration Services

Custom API development and systems integration to connect legacy on-premise systems with modern cloud applications.

**Common integrations:**
- ERP to cloud warehouse (e.g., SAP → Snowflake)
- CRM to marketing automation (e.g., Salesforce → HubSpot)
- Legacy HRMS to modern payroll systems
- IoT device data pipelines to analytics platforms

**Deliverables:** Architecture design, API development, testing documentation, handover training, and 90-day post-launch support.

**Engagement Model:** Fixed-scope project or time-and-materials retainer.

---

### 2.4 Nueva Tech Academy (Training & Enablement)

Instructor-led and self-paced training programs for cloud platforms, data analytics, and cybersecurity fundamentals.

**Format Options:**
- Live virtual workshops (half-day or full-day)
- On-site instructor-led training (Makati, Cebu, and regional offices)
- Self-paced e-learning via the Nueva Tech Academy portal

**Popular Courses:**
- AWS Cloud Practitioner Essentials (16 hours)
- GCP Associate Cloud Engineer Prep (24 hours)
- Data Analytics with NovaSight (8 hours)
- Cloud Security Fundamentals (12 hours)

### 4.4 NovaSight Platform — Common Support Topics

**Login & Access Issues**
- Reset password via the login page: click "Forgot Password" and follow email instructions.
- SSO configuration (SAML 2.0 / Google Workspace): Contact support with your domain details.
- Role changes or user deactivation: Admins can manage this under **Settings → Team → Users**.

**Data Connectors**
- Connector credentials must be refreshed every 90 days for security compliance.
- If a connector shows "Disconnected," navigate to **Data Sources → [Source Name] → Reconnect**.
- Supported connector list and setup guides: https://help.nuevatechsolution.ph/connectors

**Dashboards & Reports**
- Dashboards auto-refresh every 30 minutes by default; this is adjustable per widget.
- Scheduled reports support PDF and CSV exports delivered to email or Slack.
- Dashboard sharing: use the **Share** button to generate a read-only link (Business plan and above).

**AI Features (Anomaly Detection & Forecasting)**
- Anomaly detection requires at least 30 days of historical data to activate.
- Forecasting models are retrained weekly automatically on Growth plan and above.
- Natural language queries support English and Filipino; additional languages planned for Q3 2026.
